# Pelacak Lamaran Kerja

Ini adalah file-file aplikasinya. Ikuti panduan lengkap di dokumen
"CARA-UPLOAD-DAN-DEPLOY.md" untuk membuat aplikasi ini bisa diakses online.

Struktur file:
- `index.html` — halaman utama
- `src/main.jsx` — titik masuk aplikasi
- `src/App.jsx` — semua logika dan tampilan aplikasi
- `package.json` — daftar library yang dipakai
- `vite.config.js` — pengaturan build

Kamu tidak perlu mengerti isi file-file ini untuk men-deploy-nya.
Cukup ikuti langkah upload di panduan.
